데이터베이스 쓰기 권한 잠김

현재 연결된 파이어베이스 데이터베이스가 보안을 위해 잠겨 있어 데이터를 저장하거나 읽을 수 없습니다.
담당자 선생님께서는 아래 순서대로 접속하여 데이터베이스 권한을 풀어주세요!

✅ 해결 방법 (규칙 변경)

  1. Firebase 콘솔 사이트에 접속하여 해당 프로젝트를 엽니다.
  2. 왼쪽 메뉴에서 [Firestore Database]를 클릭합니다.
  3. 상단의 여러 탭 중 [규칙 (Rules)] 탭을 클릭합니다.
  4. 기존에 적힌 코드를 모두 지우고 아래의 코드로 똑같이 덮어씁니다.
  5. 우측 상단의 파란색 [게시 (Publish)] 버튼을 누릅니다.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
