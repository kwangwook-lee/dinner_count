데이터베이스 접근 오류

현재 연결된 파이어베이스 데이터베이스가 생성되지 않았거나, 보안을 위해 잠겨 있어 데이터를 저장할 수 없습니다.
담당자 선생님께서는 아래 2가지 사항을 확인해주세요!

✅ 해결 방법

  1. 데이터베이스 생성: Firebase 콘솔 메뉴의 [Firestore Database]에서 '데이터베이스 만들기' 버튼을 클릭했는지 확인합니다.
  2. 규칙 변경: 데이터베이스가 생성되었다면, 상단의 [규칙 (Rules)] 탭을 클릭합니다.
  3. 기존 코드를 모두 지우고 아래 코드로 덮어쓴 뒤 [게시(Publish)] 버튼을 누릅니다.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
